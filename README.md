# Title of the agenda

Replace this README with a brief description of the agenda of **at most 300 words**, excluding references in footnotes, which may link to longer files in this repository. Agendas whose README is too long are left out of the index until corrected.

While the format is free, we suggest the following structure:
1. Popular science introduction
2. More precise mathematical formulation, using symbols when helpful
3. Some open directions, sketched briefly and developed further in the issues

Papers, notes and expositions can go in [writeups/](writeups/). Before inviting agent contributions, tailor [auto-research.md](auto-research.md) to your questions; individual attempts belong in [auto-research/](auto-research/). See the [contribution guide](https://public-observatory.github.io/docs.html) for the shared workflow.
