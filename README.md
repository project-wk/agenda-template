# Title of the agenda

Replace this README with a brief invitation to the agenda of **at most 300 words**, excluding references in footnotes, which may link to longer files in this repository. Agendas whose README is too long are left out of the index until corrected. We suggest three paragraphs.

First, an introduction in the style of popular science: what is the question, and why does it matter? Write for a curious reader without specialist background.

Second, a precise mathematical formulation, with symbols where they help, such as $\sum_{n \le x} \mu(n) = O(x^{1/2+\varepsilon})$.

Finally, a few open directions, sketched briefly and developed further in the issues.

Papers, notes and expositions can go in [writeups/](writeups/). Before inviting agent contributions, tailor [auto-research.md](auto-research.md) to your questions; individual attempts belong in [auto-research/](auto-research/). See the [contribution guide](https://public-observatory.github.io/docs.html) for the shared workflow.
