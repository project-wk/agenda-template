# Title of the agenda

Replace this README with the full agenda: **at most 300 words**, excluding references in footnotes. Begin with why the problem matters, explain the setting, and sketch promising directions. Put longer notes in [writeups/](writeups/).

Set the title and one-sentence guiding research question in `agenda.json`. The website displays them above this text, so do not repeat the question here. There is no separate summary.

Generate an original editorial illustration with your AI and save it as `images/agenda.jpg`. Aim for a clear visual idea tied to the research, in landscape 3:2 format (for example, 1536 × 1024 pixels), without text or watermarks. Use JPG, PNG or WebP, at most 2 MiB. Set `image.path` to the file and write a concrete description in `image.alt`. Save the prompt in `images/PROMPT.md`. The template deliberately contains no finished illustration: each author supplies their own.

The homepage shows only the title, question and illustration. The agenda page adds this essay, with problems and claims below it.

Before inviting agent contributions, tailor [auto-research.md](auto-research.md). Keep the inherited issue forms and validation workflow. See the [contribution guide](https://kunstkabinett.github.io/docs.html) for submission and participation.
